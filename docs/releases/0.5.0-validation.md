# 0.5.0 validation — 20 October 2026

The application changes are validated. **Production publication remains blocked
on the unpatched container OS findings below and owner review/merge.** No tag,
registry push, deployment, or package-index submission was performed.

## Application and package checks

- 387 tests passed, with 79% source coverage. The single warning is Starlette's
  deprecation of its httpx-based TestClient interface.
- Ruff lint/format, strict mypy across 41 source/script files, actionlint, and
  the existing Biome checks passed. The locked environment resolves with uv 0.13.3.
- The hashed, all-extras dependency export passes strict `pip-audit` with no
  known vulnerabilities and no advisory exclusions.
- Wheel and sdist builds pass. The wheel contains the dashboard and eight
  explicit transitive security floors; DiskCache is absent.
- Independent review findings were fixed, including TLS cache-policy separation
  and security constraints being absent from wheel metadata.
- Native browser checks passed Basic authentication, stats/config retrieval,
  TLS defaults, masked proxy round-trips, citation/attribute escaping, and
  desktop/mobile navigation. The 390px overflow found during testing was fixed.
- A live direct Perplexity Sonar request passed with eight total tokens.
  OpenRouter registration and behavior are covered by automated tests, but no
  injected OpenRouter credential was available for a live call.

The offline production-image smoke exercises a real Streamable HTTP MCP
handshake, tool discovery, static scraping, Chromium rendering, cache writes,
admin authentication, masked configuration, and TLS defaults. It also verifies
that the process is unprivileged and cannot write the application or environment
directories. It passed after the final Docker changes.

Counts are installed package/advisory pairs, not unique CVEs. The critical/high
findings represent 25 unique advisories. “Available fixes” means versions
identified by the scanner for these installed packages, not proof that a finding
is harmless or unreachable.

The scan prompted removal of unused gcc/libxml2/libxslt development packages,
OS upgrades, an update to uv 0.13.3, and removal of unused bootstrap pip and its
vendored libraries. This eliminates the available fixes identified during
container validation without changing the locked application environment.

The remaining critical finding is **CVE-2026-6653** in Debian's `libxml2`
`2.12.7+dfsg+really2.9.14-2.1+deb13u3`. The package is required by the graphics
stack through `libllvm19`; it is not the libxml2 used by the application's lxml
wheel, which reports 2.14.6. That distinction does not establish the graphics
dependency's safety. Its reachability has not been proven or disproven.

Dependabot fixes are enabled. Main requires a PR, resolved conversations, and
up-to-date `quality` and `Analyze (python)` checks from GitHub Actions, including
for administrators. Force pushes and branch deletion are disabled.

The initial hosted quality and CodeQL checks passed; final check results are
